# Cafe Maple - Misskey サーバー 利用規約・プライバシーポリシー

このリポジトリは、Misskey（分散型SNS）サーバー「Cafe Maple」向けの利用規約およびプライバシーポリシーのページセットです。

## ファイル構成
- `terms.md` : 利用規約（Markdown形式）
- `terms.html` : 利用規約の表示用ページ
- `privacy.md` : プライバシーポリシー（Markdown形式）
- `privacy.html` : プライバシーポリシーの表示用ページ
- `document.css` : 各ページのスタイル設定
- `index.html` : メニューページ

## Misskey向けの設定について
MisskeyはActivityPubを用いた分散型SNSであるため、一般的なWebサービスとは異なる以下の点について規約等に明示しています。

*   **他サーバーとの通信（連合）**: 投稿内容やプロフィールが外部サーバーへ配信・蓄積されること。
*   **データの残存性**: 本サービス内でデータを削除しても、連合先のサーバーからは削除されない可能性があること。
*   **NSFW（閲覧注意）への配慮**: 露出度の高い画像などの投稿時に適切なフラグ付けを義務付けること（ドメインブロック等のリスク回避のため）。
*   **LTL（ローカルタイムライン）の保護**: Botや大量の連投によるLTLの専有を制限すること。

これらの要素が追加された規約になっています。

## カスタマイズ方法
Markdownファイル (`terms.md` および `privacy.md`) を編集することで、各規約の内容を変更できます。
HTMLファイルは `marked.js` を使用してこれらのMarkdownファイルを動的に読み込んで表示するため、内容についてはHTML側を直接直す必要はありません。

## テーマの切り替え
ライトテーマとダークテーマの切り替えに対応しています。OSの設定を反映するか、手動でトグルボタンから切り替えることが可能です。
